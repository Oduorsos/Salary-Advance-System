# Salary Advance Platform

## Overview

Salary Advance is a modern financial wellness platform that enables employees to access a portion of their earned salary before payday through a secure, employer-backed system.

The platform connects employees, employers, and payroll systems to provide responsible salary advances while ensuring transparent repayment through payroll deductions.

## How It Works

### Step 1: Employee Registration

Employees create an account and provide:

* Personal details
* Employment information
* Employer details
* Required identification documents

### Step 2: Employer Verification

The employer is contacted and verified.

If the employer:

* Is already a platform partner, onboarding proceeds immediately.
* Is not a partner, partnership discussions and onboarding may be initiated.

### Step 3: Employer Dashboard Access

Verified employers receive access to the Employer Dashboard where they can:

* Manage employees
* Upload employment records
* Verify employee information
* Review salary details

### Step 4: Employee Verification

Employees submit required documentation for verification.

Examples include:

* Employment confirmation
* Identification documents
* Payroll information
* Contract details

### Step 5: Salary Advance Application

Once verified, employees can request a salary advance.

Borrowing limits are based on:

* Monthly salary
* Employment status
* Verification status
* Employer approval policies

### Step 6: Advance Disbursement

Approved funds are disbursed to the employee through supported payment channels.

### Step 7: Payroll Repayment

Repayment is automatically deducted through payroll during salary processing.

---

## Responsible Lending Policy

To promote financial wellness and reduce financial strain:

* Employees may access a maximum of two-thirds (2/3) of their monthly basic salary.
* This ensures employees retain sufficient income for:

  * Living expenses
  * Existing loan obligations
  * Emergency needs
  * Financial stability

The platform prioritizes responsible borrowing over excessive lending.

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/salary-advance.git
```

Navigate into the project:

```bash
cd salary-advance
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
